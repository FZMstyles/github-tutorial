**Comparing Sentinel-2 and Landsat for Mangrove Mapping in The Gambia**

This project evaluates the performance of Sentinel-2 and Landsat imagery in mapping mangroves using the Google Earth Engine Mangrove Mapping Methodology (GEM V2). The goal is to determine which dataset is more effective in terms of accuracy and performance for mangrove classification in The Gambia.

**Objectives**
- Implement GEM V2 using Sentinel-2 and Landsat data.
- Compare the effectiveness of both datasets in mapping mangroves.
- Assess accuracy and performance differences between the two data sources.
